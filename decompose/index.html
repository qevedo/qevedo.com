Pick a device's native gates and decompose any gate into them, with the fewest gates. It runs in your browser: the QCC core, compiled from Rust to WebAssembly.

Try

Any gate of OpenQASM's stdgates.inc or qelib1.inc, or sqrt_swap and sqrt_iswap. Parameters can use pi, + − × ÷ and sqrt, sin, cos.

Fill in

One row per line, entries separated by commas. Complex entries like 0.5 - 0.5i or exp(i*pi/4)/sqrt(2). The first row and column belong to the first qubit, q[0].

Loading the compiler…

Single-qubit gates use an Euler decomposition, which is optimal for each basis. Two-qubit gates use a KAK decomposition with the minimal number of two-qubit gates (at most 3 for CX-like and Ising gates), or the gate's textbook definition when that is shorter. For iSWAP, √iSWAP and √SWAP the decomposition is found numerically, with the fewest uses the search reaches (√SWAP can need up to 6). ccx and cswap use their textbook definitions.
