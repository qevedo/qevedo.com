Packages

qevedo-simulator

qvd, a fast quantum circuit simulator in Rust: state vector, stabilizer, MPS and near-Clifford methods, chosen per circuit.

Rustpip install qevedo-simulator

qevedo-compiler

QCC, a hardware-agnostic quantum circuit compiler. OpenQASM 2 and 3 in and out, optimized for a device profile.

Pythonpip install qevedo-compiler

openqasm

An OpenQASM 2 and 3 parser and semantic checker for Python.

Pythonpip install openqasm

qevedo

The simulator and the compiler in one install.

Pythonpip install qevedo

Example

from qevedo.compiler import compile_source, emit_qasm
from qevedo.simulator import run

compiled = compile_source(open("circuit.qasm").read())
result = run(emit_qasm(compiled), shots=1000)
print(result.counts, result.backend)
